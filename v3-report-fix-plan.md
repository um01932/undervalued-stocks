## Sub-Task 1 — Add `--all-profiles` flag to `main.py`

**Status:** `[ ] pending`

### Intent
Allow a single `main.py` execution to run ALL 5 screener profiles sequentially on the same
fetched data, plus generate the Magic Formula CSV. This is the core UX fix — instead of
running 5 separate commands, the user runs one.

### Expected Outcomes
- `python src/main.py --universe sp500 --all-profiles --workers 8 --export csv`
  generates: `*_deep_value.csv`, `*_buffett_quality.csv`, `*_high_fcf_yield.csv`,
  `*_quality_value.csv`, `*_dividend_growth.csv`, `*_magic_formula.csv` in a single run
- Data is fetched once and reused for all profiles
- Score history appended for all 5 profiles
- `--profile` flag still works for single-profile runs (backward compatible)
- When `--all-profiles` is passed, `--profile` is ignored

### Todo List
1. Add `--all-profiles` boolean flag to `_build_parser()` in `src/main.py`
2. In `run()`, after fetching data and computing `valuation_results`, detect `args.all_profiles`
3. If `all_profiles`, loop over all 5 profile keys and call `rank_all()` + `export_results()` for each
4. Magic Formula CSV is always generated when `all_profiles=True` (even if empty, skip silently)
5. Score history append runs for each profile
6. Update `interactive_wizard()` to offer "Run all profiles" option

### Relevant Context
- `src/main.py` lines 480–628 — the `run()` function
- `apply_profile`, `rank_all`, `export_results` already exist in `src/screener.py`
- `load_profiles()` returns the dict of all 5 ScreenerProfile objects
- The data fetch (lines ~430-490) happens once and produces `valuation_results: list[ValuationResult]`
- Magic formula call at line 618 already works — just needs to always run
